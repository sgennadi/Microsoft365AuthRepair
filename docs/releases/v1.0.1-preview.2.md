# Microsoft 365 Auth Repair 1.0.1-preview.2

## What's new
1. Show exact version in every window and available version on the Updates button.
2. Display real download progress in percent and MiB, with Cancel and Open folder.
3. Compare both Stable and Preview channels and show short numbered changes.
4. Correct the Diagnostics & Reports button label.
5. Accept pending JSON created by 0.1.0-preview.1 without exposing account details.
6. Review sanitized WAM/Entra states, confirm public GitHub Issue consent, then Send anonymously.
7. Verify GitHub receipt before marking a report delivered or closing its window.

## Deployment notes
- Stable 1.0.0 remains unchanged.
- Owner must update the shared Google Apps Script deployment to schema v3 and add GITHUB_M365_ISSUES_TOKEN (Issues write on Microsoft365AuthRepair only). No GitHub token is built into the EXE.
- Preview is for pilot testing. Automatic EXE replacement is not yet enabled; use manual install after download and verification.
