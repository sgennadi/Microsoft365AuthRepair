# Microsoft 365 Auth Repair v1.0.2-preview.28 — direct TPM/BitLocker security controls

**Preview only.** Stable 1.0.1 remains unchanged.

## Changes

1. **Less navigation.** The main Check & Diagnose TPM & BitLocker card shows three concise links near its title: **View full details**, **Windows BitLocker settings**, and **Advanced device security**. You no longer need to open the read-only detail inspector to find Advanced.
2. **High-DPI and RTL friendliness.** The links use a wrapping WinForms flow row above the 14 status tiles instead of competing with the card heading for horizontal space. Keyboard focus and accessible names are provided for English, Russian and Hebrew.
3. **Read-only by default.** During a live Check & Diagnose, full details remains accessible using cached evidence. The native Windows BitLocker settings link and Advanced are disabled until the scan completes; the diagnostic itself changes no device protection state.
4. **Clear privileges.** Non-elevated users can open Advanced to see its capabilities, but sensitive actions are disabled. There is no automatic elevation, silent change or WAM reset. A properly authorized administrator must explicitly run elevated and confirm each security operation.
5. **Less misleading TPM button.** Opening the Windows TPM console is labeled **Open TPM management** with a neutral settings icon, not a red destructive button. Its existing typed confirmation and administrator check remain, and TPM Clear itself can only be triggered manually inside Windows.
6. **Existing advanced operations unchanged.** Restricted local recovery-password export, suspend one reboot, resume, start decryption and native Windows tool launch retain their existing confirmation gates and safety restrictions. Recovery secrets remain out of Activity and anonymous diagnostics.
7. **Regression tests.** UI self-tests verify the new direct links, wrapping composition and busy-state availability, in addition to existing Windows x64/ARM64 and privacy checks.

## What to test

On a Windows 11 device, open **Check & Diagnose**. During the scan confirm **View full details** is available and the other two links are disabled. On completion, check that all three shortcuts are visible at the top of the device card at 100%, 150% and 200% scaling. **Advanced device security** should open directly, with privileged buttons disabled for ordinary users and the warning visible for elevated administrators. Do not perform TPM Clear or BitLocker decryption in a UI test.

For reporting: the separate **GATEWAY_invalid_evidence** problem shown with Preview.27 is a mismatched Google Apps Script allowlist. This security-shortcut release does not alter the diagnostics receiver; updating the independent server contract remains required.
