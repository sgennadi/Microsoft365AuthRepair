# Microsoft 365 Auth Repair 1.0.1-preview.13

## What's new
1. **Microsoft Learn troubleshooting:** The offline EN/RU/HE guide connects WAM, CloudExperienceHost, PRT, Conditional Access, MFA, network, RDS/VDI and Office licensing symptoms to a read-only check, safe action and an official documentation link. No raw sign-in data is sent.
2. **Native Office subscription license diagnostics:** The C#/.NET Check & Diagnose reads Click-to-Run product hints, vNext indicators, Shared Computer Activation configuration and local license file counts. No VBS, PowerShell or Microsoft license script is executed and local hints are never misrepresented as proof of active entitlement.
3. **Office / Visio / Project 2024 Volume inventory:** Dedicated Office WMI view shows license status and last five key characters, never full keys. Find KMS checks configured/discovered Office KMS host and DNS SRV; users can enter an approved hostname/port (1688 default).
4. **2024 Preview conversion:** For an independently verified Office-family Volume 2024 SKU and known Preview key, administrators can explicitly approve removal of that exact old Preview product key BEFORE installing the official 2024 KMS GVLK or authorized MAK. A separate warning requires confirmation. The app checks the selected Office application ID, exact activation GUID and last-five key before making a change.
5. **Protected products and explicit failure states:** Unverified Preview 2026, Microsoft 365 subscriptions, Retail and unrelated product SKUs are read-only. If replacement/activation fails, the app explains that the old Preview key may already have been removed. MAK key text is masked, cleared after use and excluded from diagnostics.
6. **Stable untouched:** Existing WAM repairs, All users wizard, read-only Entra checks, UniversalUpdater and anonymous Google report gateway are unchanged. Stable v1.0.0 is not modified.

## Verification and pilot requirements
- Windows x64/ARM64 build and x64 GUI smoke checks must pass before merge and release.
- Unit-like GUI checks enforce strict Volume 2024 edition, known Preview suffix, unsupported 2026 block, no operation without UAC, and user consent before Preview key deletion.
- Live MAK/KMS activation, DNS discovery, Office/Visio/Project coexistence, and rollback/recovery are not safely reproducible in CI. Test with a spare Office 2024 Preview workstation before deployment.
- Never treat a DNS SRV response as verified KMS reachability. A KMS host requires supported Office Volume License Pack and sufficient activation threshold. Switching an unsupported edition requires Office Deployment Tool; a product key alone is insufficient.
