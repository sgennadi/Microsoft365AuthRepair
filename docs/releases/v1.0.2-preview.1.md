# Microsoft 365 Auth Repair 1.0.2-preview.1

Preview for Windows x64 and ARM64. The production Stable release remains **v1.0.1**.

## What's new

1. **Read-only TPM health:** detect whether TPM is present, ready and temporarily locked out using Windows `Get-Tpm`. A blocked/unsupported probe reports **Unknown**, not a fault.
2. **Entra device-key health:** display `TpmProtected`, `KeySignTest`, and `AadRecoveryEnabled` from an allowlisted `dsregcmd /status` read, without collecting key IDs or certificates. **KeySignTest requires elevation**, and its absence is not a failure.
3. **Windows Hello and BitLocker:** read `NgcSet` in the actual Windows user's session and check OS-volume BitLocker protection without collecting keys or protectors. `NgcSet=NO` and BitLocker Off are neutral indicators, not proof of failed Microsoft 365 sign-in.
4. **Smart Repair safety:** make verified TPM/key-signing problems take priority over BrokerPlugin re-registration. No automatic TPM clear, PIN reset, BitLocker modification, key-container deletion or device disconnection.
5. **Code search:** add explanation for `0x80090011`, `0x80090030`, `0x80090031`, and `0x80090034`; preserve `0x80090016`, WAM 1001 and AADSTS checks.
6. **Privacy & QA:** retain the existing anonymous transport allowlist, so TPM/BitLocker/Windows Hello keys, IDs and statuses stay local. Add UI, recommendation priority and privacy self-tests.

## Important limitations

- TPM cmdlets can require permissions and Windows PowerShell module availability. Unknown means *not verified*, not healthy or broken.
- `KeySignTest` can only be trusted when Windows supplies a value; it requires administrator privileges. Running elevated as a different user can make WAM, PRT and Windows Hello results misleading.
- Actual user sign-in to Word/Outlook/Teams, hybrid-join recovery, a temporarily locked TPM, hardware ARM64, BitLocker recovery and EN/RU/HE RTL/200% DPI require a controlled Windows pilot. A passing CI build is not a proof of live authentication.
- Keep BitLocker recovery information accessible before any separate IT-managed device repair. This application does **not** clear TPM, unjoin Entra or touch cryptographic keys.
