# Microsoft 365 Auth Repair 1.0.2-preview.23 — visible TPM & BitLocker results

**Preview only.** Stable 1.0.1 is unchanged.

## What's new

1. **Visible TPM & BitLocker card:** after **Check & Diagnose**, a separate security card appears immediately below the WAM/Entra status grid, not hidden within Smart Recommendation or raw technical diagnostics.
2. **Eight read-only indicators:** TPM presence, readiness, temporary lockout, system-drive BitLocker protection, system-drive encryption state, Memory Integrity / HVCI, DPAPI policy and writable domain controller availability. Each reports a categorized state, **Needs review** when supported, **Not applicable** when appropriate, or **Not verified** if the evidence was unavailable.
3. **Easy navigation:** a **TPM & BitLocker** shortcut in the Diagnostic results banner scrolls directly to the security card. When results have been collapsed, the same shortcut expands and navigates. The card's **View full details** link opens the existing read-only inspector with TPM version, firmware category, AIK, EK and other detailed status.
4. **Consistent responsive layout:** security tiles reflow into one or two columns based on window width and display scaling; labels are localized in English, Russian and Hebrew, and are accessible to keyboard and screen-reader navigation.
5. **No stale or invented healthy results:** starting Check & Diagnose, re-registering WAM or resetting Office sign-in clears the previous device card. Incomplete provider evidence displays **Not verified**, never "healthy". The card uses the existing Preview.22 read-only scan; clicking **View full details** does not repeat a WMI query.
6. **Self-test coverage:** x64 GUI smoke tests verify that the primary screen owns the card and shortcut, both status colors, the details link and the privacy-safe unknown states. CI also compiles self-contained Windows x64/ARM64 binaries.

## Important distinctions

These indicators report **Windows device-security configuration**, not proof of Microsoft 365 app sign-in or TPM hardware health. BitLocker OFF, a missing TPM, or a disabled Memory Integrity policy can be expected in some environments. TPM lockout or an encrypted OS volume with protection OFF warrants administrator review, not automatic changes.

No Clear-Tpm, BitLocker key/protector export, Windows Hello PIN reset, Entra leave or WAM/Office cache deletion is performed by Check & Diagnose. Device identifiers, recovery secrets and raw WMI output are not shown in the card, copied by Activity or uploaded automatically.

**Hardware pilot:** validate on the Windows device used for the Preview.22 successful 2-second scan, including 100/150/200% DPI and Hebrew RTL. Passing CI is not a substitute for end-to-end app sign-in verification.
