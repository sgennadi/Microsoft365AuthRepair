# Microsoft 365 Auth Repair 1.0.1-preview.12

## What's new
1. **All users mini wizard:** Selecting All users opens a concise 3-step guide for existing local/domain Windows profiles. Choose protected EXE or standalone PowerShell (WAM re-registration only), whether to start at existing user sessions or defer all tasks to next sign-in, then select **Save settings only**, **Continue to Re-register WAM**, or **Continue to Reset Office sign-in**. Save only is the default.
2. **Optional one-flow repair:** After the wizard, the application can open the normal repair confirmation directly. On non-elevated Windows accounts, UAC is required; the elevated process receives a strictly allowlisted *review intent* flag. Repair and reset never execute automatically upon selection, wizard completion or UAC. Full Office sign-in reset remains EXE-only.
3. **Collapsible diagnostic results:** The main Check & Diagnose section can collapse to a status line, or expand back to the same six interpreted Entra/WAM signals and optional technical details without re-running the diagnostic probe.
4. **Sign-in error guide:** A compact, offline EN/RU/HE lookup explains recognized AADSTS, WAM/1001 and 0x80090016 cases and distinguishes local WAM repair from MFA, Conditional Access, Entra device trust, credential or TPM investigation. No account passwords, tokens, raw logs, or HTTP upload are involved.
5. **Preserved safety:** Existing profile-only eligibility, affected user's session, scheduler, read-only diagnostics, explicit report transmission, Google gateway, SHA-256 updater verification and Stable v1.0.0 remain unchanged.
