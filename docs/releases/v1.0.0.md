# Microsoft 365 Auth Repair 1.0.0 (Stable)

First stable baseline based on the tested `0.1.0-preview.2` source. No changes to WAM repair or reset behavior were made when promoting to Stable.

## What's new
1. First stable version with a permanent `v1.0.0` tag.
2. Self-contained, single-file Windows EXE packages for x64 and ARM64 (.NET 10 WinForms; no separate runtime installation).
3. Branded Windows application icon and DPI-aware action/status icons.
4. **Repair sign-in**: re-register Microsoft Entra WAM / Microsoft.AAD.BrokerPlugin for the signed-in user.
5. **Advanced**: optional full Office/WAM identity reset and admin-selected all-profiles tasks, with explicit UI confirmation.
6. UniversalUpdater Stable/Preview detection, SHA-256 downloads, and local UniversalDiagnostics report preview.
7. EN, RU, HE localization and Windows High Contrast / HiDPI support.

## Important limitations
- **Do not deploy the advanced full reset to all users without pilot validation.** This operation deletes sign-in caches and may sign users out. Real domain/Entra repair, all-users interactive-task behavior, and physical ARM64 execution have not yet been verified.
- Stable here means the starting baseline and versioned release; it is **not a claim of complete production field testing**.
- Automatic EXE replacement is deliberately disabled until a safe, tested updater helper is available.
- The app does not call `dsregcmd /leave`, alter Hybrid Join or resolve device-side `AADSTS50155` errors.
- A diagnostic report is stored locally only after explicit approval; nothing is uploaded automatically.
