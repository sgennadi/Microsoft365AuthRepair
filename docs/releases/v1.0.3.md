# Microsoft 365 Auth Repair v1.0.3 — Stable

Released 2026-11-16. Portable Windows x64 and ARM64 ZIP packages.

## Automatic main-window height

The window now grows or shrinks vertically when Check & Diagnose completes, WAM/Office findings or the Activity journal expand/collapse, or localized text reflows. The width is never changed. Resizing stops at the current screen's usable working area, leaving the Windows taskbar available. Any content beyond the screen stays accessible with the inner scrollbar. Maximized, manually resized and snapped windows are left alone.

## Regression and safety

CI checks x64/ARM64 self-contained builds, Windows GUI initialization, safe background workers, UI state and deterministic geometry at 100%/200% DPI. Real display testing at 100%, 150%, 200% and in English/Russian/Hebrew remains recommended. No TPM Clear, BitLocker state changes or login-token deletion is performed by layout adjustments.

Anonymous reports remain user-controlled and require the previously deployed Google Apps Script Gateway v4 for 29 fixed categorical fields. If the receiver has not been redeployed, reports remain local.
