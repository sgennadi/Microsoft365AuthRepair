## Deployment notes

- **Preview** for controlled testing. Stable **v1.0.0 remains unchanged**.
- The existing shared Google Apps Script owner must update the live deployment to gateway schema v3 and add a dedicated `GITHUB_M365_ISSUES_TOKEN` with **Issues:write on Microsoft365AuthRepair only**. GitHub source changes alone do not deploy Google Apps Script.
- Reports appear in **public** GitHub Issues and accept no personally identifying summary, credentials, raw logs or token data. Only typed WAM/Entra status fields are transmitted.
- The updater downloads and validates a release; **automatic replacement of a running EXE is not implemented** yet. Open the verified ZIP to install manually.
- All-users scheduling and live Hybrid Join remediation require real Windows domain QA; nothing changes `dsregcmd /leave`.
