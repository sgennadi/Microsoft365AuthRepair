# Microsoft 365 Auth Repair 1.0.1-preview.11

## What's new
1. **Six readable diagnostic signals:** Check & Diagnose presents AAD BrokerPlugin, Entra join, AD domain, device authentication, Azure AD PRT, and WAM account in a compact grid with localized values (EN/RU/HE).
2. **Conservative statuses:** Known working signals are positive; absent BrokerPlugin, failed device auth, missing PRT or WAM account require attention; nonjoined AD/Entra configurations are neutral, not automatically broken; unavailable values remain unknown.
3. **Adaptive diagnostics panel:** Two columns where space allows, otherwise one. A clear heading, relevant findings, and next steps remain visible; full read-only data is still available through Show technical details.
4. **Adaptive dialogs:** Settings, Diagnostics & reports, and Send anonymously now fit their opening size to the monitor's work area and DPI. Long checkbox labels and localized guidance wrap when space is limited.
5. **No functional regression by design:** Existing current/all-user repair, cache reset, scheduling, explicit anonymous Send confirmation, Google gateway, and UniversalUpdater channel/version checking are not changed. Stable v1.0.0 is untouched.

## Verification
- Windows GitHub Actions must build x64 and ARM64 self-contained EXE packages and run the x64 GUI smoke test successfully before publication.
- The UI smoke test includes six diagnosis tiles and conservative handling of unknown and neutral signals.
- Real 100%, 150%, 200% Windows DPI, RTL Hebrew, x64/ARM64 runtime, UAC and live Entra/WAM behavior require pilot testing.
- The read-only diagnostics do not verify an actual Office, Outlook, Teams or OneDrive sign-in. They do not initiate repair or upload any report.
