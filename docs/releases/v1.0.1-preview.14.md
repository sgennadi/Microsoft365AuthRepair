# Microsoft 365 Auth Repair v1.0.1-preview.14

## What's new
1. **Readable main header:** Settings occupies the main title row. The Language selector has a labeled, separate row and more space for English, Russian and Hebrew at higher DPI.
2. **Installed Office first:** Office, Visio and Project Volume licensing now shows one preferred licensing record for each installed product and prioritizes a WMI status of `Licensed` with a valid partial key. Empty `Unlicensed` MAK/KMS template entries remain available through **Show other WMI records**, rather than obscuring an already activated Office.
3. **Protect working licenses:** An activated product cannot be changed by the KMS/MAK action. An empty WMI template record cannot trigger a key change when a valid activated record already exists for that edition.
4. **Suggested official KMS key:** For verified Office LTSC 2024 Standard/Professional Plus, Visio LTSC 2024 Standard/Professional and Project 2024 Standard/Professional Volume editions, show the Microsoft-published GVLK in a read-only copyable field. The appropriate GVLK is used only after the normal KMS activation confirmation. Retail, subscription and unverified 2026 Preview remain protected.
5. **Quieter Office license window:** Replace large Refresh and Find KMS buttons with compact inline links. Initial inventory and KMS host discovery run automatically, with a manual host/port still available. Reduced the initial window height and removed the stretched empty footer.
6. **Preview-only:** WAM repair, All users mini wizard, consent flow, diagnostic reporting, updater and Stable v1.0.0 are unchanged.

## Verification
- Windows x64/ARM64 release builds and x64 WinForms smoke tests must succeed.
- GUI smoke tests verify Settings and Language separation, activated-record priority and hiding of redundant WMI templates, optional full record list, and GVLK matching for six 2024 Volume editions.
- Existing license replacement still requires elevated administrator, exact installed product verification and explicit final confirmation.
- Live KMS/MAK operations and high-DPI English/Russian/Hebrew visual inspection still require pilot validation. DNS discovery is not proof of actual KMS activation.
