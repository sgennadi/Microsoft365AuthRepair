# Microsoft 365 Auth Repair 1.0.1-preview.10

## What's new
1. **Responsive report generation:** Generate report runs the local AppX and dsregcmd probe off the WinForms UI thread; the window stays responsive.
2. **One clear review surface:** Diagnostics & reports no longer displays a second copy of the raw JSON. The outgoing allowlisted data is displayed in the dedicated Send anonymously dialog.
3. **Saved reports:** Send saved report opens a queued local JSON for review, without sending it automatically.
4. **Safe submission:** The approval checkbox remains checked by default as requested, but delivery still requires a deliberate click on Send anonymously. Confirmed GitHub submissions close the dialogs; timeouts and failures retain the local report.
5. **Preserved behavior:** Entra/WAM repair and full reset, user scopes, update installation, Google Apps Script gateway and Stable v1.0.0 are unchanged.

## Verification
- GitHub Actions Windows x64/ARM64 self-contained publish and x64 GUI smoke test must pass before promotion.
- Manually confirm EN/RU/HE text, 100%/150%/200% display scaling and report-generation responsiveness on Windows.
- No network call is initiated by Generate report. The remote receiver sees data only after Send anonymously is explicitly clicked.
- Do not retry after an ambiguous timeout without first checking GitHub Issues for a possibly delivered report.
