# Microsoft 365 Auth Repair v1.0.1-preview.17

## What's new

1. **All users: read-only task status.** New compact status window (also linked from the All users wizard) shows the latest local task records: waiting, running, worker-reported success, worker-reported failure, Task Scheduler attention, expired or unconfirmed. Refresh is manual, never auto-runs or deletes tasks.
2. **Protected per-user history.** Each successfully registered task gets an administrator-owned local record under ProgramData. Task Scheduler state is correlated with the affected user's own per-run `.attempted`, `.ok` and `.failed` markers; the worker needs no upload or domain-wide permissions. An absent task alone is never "success".
3. **Conservative results.** A worker success receipt means the WAM repair/reset operation reported success, **not** that Word, Outlook, Teams or OneDrive authenticated. Task Scheduler exit code 0 without a per-user success receipt remains unconfirmed.
4. **Safer cleanup classification.** Failed/attention tasks are not treated as completed and cannot be removed by the existing completed/expired cleanup choice. Waiting or running tasks remain protected; shared workers can only be cleaned when the entire task folder is empty.
5. **Clear diagnostic scope.** In All users mode, the main read-only button is **Check this account only**, identifying that it tests the app's active Windows account, not every profile. The bulk workflow remains wizard-only.
6. **EN/RU/HE and HiDPI.** New status and scope strings are localized. The status table wraps long status descriptions; responsive sizing follows the existing per-monitor DPI layout.

## Safety and verification limits

- Stable v1.0.0 is unchanged. No cleanup, repair, credential collection or GitHub submission occurs when opening task status.
- Only administrators can read the protected per-machine history. It contains task identifiers and Windows user SIDs but no passwords, keys, tokens or sign-in report data. User marker files remain under each profile's LocalAppData.
- Older tasks registered before Preview.17 may appear from Task Scheduler while still registered, but cannot be reliably reconstructed once removed.
- **Live pilot required before Stable:** verify on a disposable Windows PC with existing local/domain profiles, both EXE and PS1 workers, online/offline sign-ins, 100/150/200% DPI and Hebrew RTL. Windows CI smoke checks cannot prove these end-to-end conditions.
