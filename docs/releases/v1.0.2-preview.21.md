# Microsoft 365 Auth Repair v1.0.2-preview.21 — bounded Check & Diagnose

**Preview (test only).** Built on Preview.20; Stable 1.0.1 is unchanged.

## What's new

1. **Correct diagnostic status:** Check & Diagnose now explicitly says **Read-only sign-in check**. The prior generic "Microsoft applications may close" text described WAM repair, not this diagnostic action.
2. **Four concurrent independent sections:** WAM/Entra, Office licensing/activation, TPM/BitLocker/DPAPI/AIK and HTTPS preflight run independently. Completed sections update the live 1/4–4/4 counter with elapsed seconds.
3. **Bounded UI wait:** Show all available results within a total of **60 seconds** even if a Windows WMI provider blocks or a PowerShell child cannot exit. Unfinished sections become **Not verified**, not success or confirmed failure.
4. **Cancellation:** A temporary **Cancel check** button stops waiting and returns the window to its normal state. The check does not delete credentials, sign users out, clear TPM, change BitLocker, or alter Office/WAM registration.
5. **Avoid repeated blocked WMI queries:** If a user repeats a check while a previous *read-only* native provider is still blocked within this process, the scanner reuses that pending operation instead of spawning another.
6. **Bounded output drain:** A helper process exiting without closing inherited stdout/stderr handles can no longer indefinitely hold a diagnostic result.
7. **Privacy:** Only the existing strict anonymous report allowlist is transmitted after an explicit review and approval. Raw PowerShell, WMI, domain/user identifiers, tokens, TPM authorization and BitLocker recovery keys remain local.

## Not tested by CI

Windows 2025 CI runs x64 and ARM64 build, UI smoke tests, and static/self-test checks. It cannot emulate a hung WMI provider, actual TPM/BitLocker, blocked AppX/PowerShell on an enterprise endpoint, or verify Microsoft 365 cloud sign-in. Test with a real current-user Windows session, Office 2024 and Microsoft 365, and 100%/150%/200% DPI in English/Russian/Hebrew before any Stable promotion.

A scan may end with partial evidence at the 60-second deadline. The underlying Windows provider query is read-only and might still be completing; such timed-out probes are not forcibly terminated. There is no automatic retry, WAM reset, or elevation in Check & Diagnose.
