# Microsoft 365 Auth Repair v1.0.2-preview.29 — Advanced device security layout

**Preview only.** Stable 1.0.1 is unchanged.

## What changed

1. **Compact, consistent Windows layout.** Advanced device security uses a shorter initial window, a constrained content width on large or maximized desktops, regular spacing and section headings.
2. **Grouped, understandable operations.** Safe / informational contains *Export recovery key*, *Windows BitLocker settings* and *Open TPM management*. Protection controls contains *Suspend (1 reboot)* and *Resume protection*. **Danger zone** contains only *Decrypt / Turn off*.
3. **One explicit authorization section.** The recovery acknowledgment is unchecked by default and the exact typed phrase remains mandatory for privileged actions: EXPORT, SUSPEND, RESUME, DECRYPT and CLEAR TPM. The field auto-capitalizes letters for convenience but is never pre-filled. A separate Yes/No warning still follows.
4. **Responsive action rows.** Buttons keep consistent widths with short descriptions beside them, and descriptions move below the buttons when there is insufficient width. Vertical scrolling handles small screens/100–200% scaling without clipping critical actions.
5. **Persistent footer.** The operation status remains on the left and Close on the right even when the advanced list scrolls. The dialog cannot close while a sensitive operation is executing.
6. **Privacy and safety unchanged.** Export still requires a new local NTFS file with restricted ACLs. Recovery passwords are not placed in the UI, logs or reports. TPM management only opens Windows' native console; Clear TPM itself is never executed by the app. Suspend, resume and decrypt still target only the OS volume and require elevation and explicit confirmation.
7. **Windows tests.** Additional GUI self-tests check the section grouping, action button roles, confirmation defaults, scrollable content and fixed footer. Windows x64 and ARM64 CI/publishing gates are retained.

## Field acceptance

Run the preview on Windows 11 at **100%, 150% and 200% DPI**, in **English, Russian and Hebrew**, including a narrow window and maximized window. Confirm the text stays readable, there is no horizontal clipping, scrolling leaves Close visible, and non-elevated users cannot perform privileged operations. The native BitLocker settings shortcut should still open Windows normally.

Do not exercise TPM Clear, BitLocker decryption, suspension or recovery-password export in a cosmetic layout smoke test. These need separate, explicitly approved device-specific validation.
